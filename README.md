# space_data

This repository contains selected space data collections from the local dataset.

## Included directories

- `admin/`
- `catalogs/`
- `historical_tle/`
- `rockets/`
- `satellites/`
- `tle_data/`

## Ignored directories

The following top-level directories are intentionally excluded from version control:

- `historical_tle_old/`
- `historical_tle_older/`
- `McCant TLE history/`
- `rockets_251022/`
- `z_satcat/`

## Notes

- A `.gitignore` file is configured to keep the repository focused on the selected directories.
- This repository is initialized for tracking curated space data assets.
